# Portfolio

This is my personal portfolio built with Next.js. It highlights my projects, experience, education, and a few links if you want to reach out.

## Run locally

```bash
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

## What’s inside

- A short intro about me
- Selected projects with source and live links
- Work experience and education
- Contact links at the bottom of the page

## Notes

The content for the site lives in `lib/data.ts`, so that is the main file to update if you want to change project text, experience, or links.

## Deploying

The app is set up for Vercel, so deploying is usually just a matter of pushing the latest changes and importing the repo.
